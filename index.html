GeomFlow

Geometry-aware adaptive diffusion model via Hessian information.

hz-cao / Haozhuo Cao, Xiaorui Wang, Liyang Yu, Wangcai Ding

Paper PDF Code Architecture PDF

Overview

GeomFlow addresses spatially uniform diffusion by adapting the reverse process to local geometric complexity. A learnable noise schedule controls global temporal dynamics, while a Hessian-trace estimator modulates local diffusion strength.

Learnable Noise Schedule

The LNS pathway parameterizes beta(t) and aligns global noise progression with the score network.

Geometric Complexity Estimator

Hutchinson trace estimates local curvature from the score field and produces gamma squared for spatial modulation.

Preconditioned Sampler

The reverse update uses gamma squared as a Riemannian-style preconditioner for geometry-aware image generation and inpainting.

Reported Results
